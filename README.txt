Bosetech Phone Plug - Catalogue
================================
Everything is in one file: index.html (open it in VS Code, or double-click to view in a browser).

Where to edit:
- Devices, specs and prices: the "var D=[ ... ]" list inside the <script> near the bottom.
  Each row: [brand, model, RAM/storage, battery, display, deposit, daily payment, old price or null]
- Referral code and order link: search for "REF011" and "eazy2get.com".
- Business name: search for "BOSETECH PHONE PLUG" and the <title> tag.
- Colours: the :root { --red, --or, ... } variables at the top of the <style> block.

To put it online with your own link: upload the folder to Netlify, Cloudflare Pages or GitHub Pages.
